# 全片地图 · 画面向

只在分支 = 画面向时读这个文件。剧情向读 song-map.md。

不编情节（没有遇见、偷瞄、进教室）。靠 **词里的意象 → 有关联的场景** + 光、焦、运镜、表情把歌唱完。大部分镜头仍是人物对嘴。

H3 本来就容易把人脸和同一套布景复读。地图必须主动换空间，不能靠换角度硬撑同一扇窗。

## 输入

有歌名就搜词，用来定 **这一世界里有哪些地方**（故乡夜、村路、炊烟、月亮、桂花、篝火），不要把意象写成事件。听感以大桶说的氛围为准。

必有：歌名或歌词大意、音频总时长 T、氛围。人物参考有就锁。画面向不需要互动对象。

## 先锁这一世界，再按词换房间

地图第一句是 **Look + 这支 MV 是哪个世界**，不是「她看见他」，也不是「窗边唱完整首」。

1. **这首歌长什么样？** 一句 Look（胶片、色温、颗粒、焦段倾向）。全片锁定，不换滤镜。
2. **场景跟词走，彼此要有关联。** 倾向：**一句一个场景，或两句换一个场景。** 不是硬性。慢歌、同一意象的两句可以留在同一空间换光/轴/焦；词已经换意象了就换地方。禁止连续 3 段还在同一扇窗、同一面墙、同一套怼脸。禁止每段跳一个毫无关系的新世界（教室切海滩切机舱）。
3. **光怎么变？** 每段指定主光源和软硬。相邻段要有差。不要六段都窗侧光。
4. **人要被放进空间里。** 换场景时至少有一镜是中景/中全，让身体和地点同时在，再切近。禁止整首只有大特写侧脸。

禁止：进教室、偷瞄、擦肩、对视来推进。那是剧情向。

## 气口格

有 SRT 读 srt-timing.md。装段仍按气口（单段 ≤15 秒，总和 = T）。**换场景跟词和节奏走，不要跟 15 秒格子走。** 一段里可以一句一景（硬切换），也可以两句同景换轴。

## 表

```
| 段 | 起-止 | 时长 | 词/气口 | 空间（跟哪句词） | 光 | 调度（景别+运镜+身体，不要只写换轴） |
```

出完这张表就停。

## 段内写什么（确认地图之后）

读 mv-grammar.md。每一镜 Timeline 必须有：

- 景别 + 拍摄轴 / 高度
- 光：从哪来、落在哪
- 焦：shallow / rack from X to face，不要段段 shallow on eyes
- 表情 + 呼吸（可见的）
- **身体：贴这句词、这个空间的一个简单动作。** 慢走、停步、低头、抬头看月、靠门、换重心。慢歌也要写，禁止站桩张嘴。运镜锁死也不等于人冻住。不要走成剧情向的进门偷瞄。细节见 lipsync-performance.md。
- `Mouth singing`
- **镜内运镜：按这句词写，不要段段 Locked-off，也不要为了有运镜而写。** 静的词可以锁死；空间词、长句可以极慢推、轻微横移、rack。近景运镜必须慢，把稳定性让给嘴。

一段里最多 **1 镜** 可以不对嘴。

禁止当成公式的套路：

- 三四段窗边：MCU 正面 → MCU 侧面贴玻璃 → CU 流泪
- 段段 Locked-off 怼脸
- 段段同一层雨玻璃虚实

虚实、前景、rack 要用，但每次换东西：烟、桂花、火、门框、肩，不要每段都是窗。
