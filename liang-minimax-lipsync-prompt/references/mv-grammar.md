# MV 分镜语法

本文件只管 **一段里面** 怎么切。故事在 song-map，光影在 visual-mv。段长 3–15 秒，切点一位小数，见 srt-timing。

刀数和景别规则 **按分支**，不要混用。有 SRT 时先读 srt-timing.md：**气口优先于平均秒数**。短句不切开；长句可以中切近。无 SRT 才 15 秒均分。

## 1. 剧情向刀数

15 秒：**最少 3 镜，正常 4 镜，大约 3–4 秒一切。** 7–8 秒停在同一画面会无聊，禁止。

| 速度 | 15 秒里 | 单镜时长 |
|---|---|---|
| 慢歌 / 情歌 | **3 镜** | 约 4–5 秒 |
| 中速 / 甜歌 | **4 镜** | 约 3–4 秒 |
| 快歌 / 副歌 | **4 镜** | 仍 3–4 秒 |

秒数不准均分：`3/4/3/5` 可以，`4×3.75`、`5+5+5` 不行。

## 2. 画面向刀数

15 秒：**大约 3 镜，约 5 秒一切，不要定死。** `6/5/4`、`5/6/4`、`7/4/4` 都可以。禁止 4 刀远近远近，也禁止一镜 15 秒。

待在中全、中、中近、近。换新空间时先用中景把人放进去。远 / 全仍只给 ≤3 秒。禁止整首 MCU/CU 怼脸。

## 3. 景别

阶梯：EWS → WS → FS → MLS → MS → MCU → CU → ECU。

**剧情向：** 相邻两镜至少跳两级。禁止 MCU 接 CU、MS 接 MLS。4 刀骨架：`中全/全（做事）→ 近（反应或唱）→ 中全（两人）→ 近（唱）`。同一动作换机位再拍 = coverage，禁止。

**画面向：** 不强制跳两级。同景别换轴、换高度、换焦都是新画面。禁止把跳两级当节拍器打成 `MLS→CU→MLS→CU`。

H3 远景全景糊。WS / FS **默认 3 秒，硬顶 4 秒**。

## 4. 剧情向：切在下一拍

每一刀必须同时是下一拍故事 + 乐句附近。演和唱大约一半一半。跨段：上一段若停在近，下一段用中全开在下一个故事动作上。

## 5. 画面向：切在词的意象上，不是切在脸上

每一刀至少换一样：空间、主光、焦平面、拍摄轴、运镜。不要只换远近，也不要只换左右脸。

运镜按词，不按清单。可以锁死、极慢推、轻微横移、rack；禁止溶解、黑场、白场、闪白。镜间只硬切。不要段段 Locked-off，也不要每镜都推一遍。**机位锁死仍要写身体：** 慢走、低头、看词里的东西，禁止站桩张嘴。

常见（举例，不是公式）：

- 新空间：中景（人在地点里，可极慢推）→ 中近对嘴
- 两句同景：中近 + rack 或换轴，第二句再近
- 长句心伤：锁死或极慢推近，不要再切回窗

大部分镜 `Mouth singing`，不要把歌词原文写进 Timeline。一段最多 1 镜空氛围。近景运镜必须慢。Look 加 `no caption overlay` 和空底栏。Timeline 禁用 subtitle / lyrics / karaoke / prompt / text。每一镜 `Clean frame bottom.` Editing / Audio 贴 SKILL.md 禁字幕句。
