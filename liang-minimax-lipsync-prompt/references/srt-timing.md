# 切段时间（SRT 优先，一位小数秒）

听不到音频。切点最多 **一位小数**（12.3），不要收成整秒。气口对齐到 0.1 秒即可。

前奏 / 尾奏：MV 叫前奏尾奏；讲解 / 脱口秀叫片头片尾。处理一样。无词段不对嘴。

## 先要音频总时长

播放器里这条音轨有多少秒，记作 **T**（保留一位小数，不要先取整到秒）。没给就问，不要用 SRT 最后一条冒充 T。

SRT 只标有词的句子。对不上时：

| 对不上 | 怎么处理 |
|---|---|
| 第一条起 &gt; 约 1s | `0` 到该句是 **前奏** |
| 最后一条止 &lt; T | 最后一句到 T 是 **尾奏** |
| 最后一条止 ≈ T（差 &lt;0.2s） | 没有尾奏，切到 T |
| 最后一条止 &gt; T | 停下来问：音轨比字幕短，是切到 T 还是时长给错了 |

前奏/尾奏没有歌词，画面向给不对嘴的脸或空镜（一段最多 1 镜空氛围仍适用；尾奏整段都可以不对嘴）。剧情向可以纯演。

尾奏/前奏装段：&lt;3 秒并进邻段；3–15 秒单独一段；&gt;15 秒按 15 秒切开。

## 有没有 SRT

1. **先向大桶要 `.srt` / `.vtt`。** 有就按气口切。
2. **没有** → 退回约 15 秒一段，末段吃剩余。标明「无字幕，按秒切」。不要假装知道气口。
3. 有 SRT 时不要再用 15 秒均分。

## 有 SRT：抽出气口，对齐到 0.1 秒

每条字幕：`起 --> 止  词  时长`

- **句界**：一条字幕的起/止
- **硬气口**：两条字幕空隙 ≥1s
- **连句**：空隙 &lt;1s，不要在这里拆段
- **短句**：一条 ≤ 约 3.5 秒 → 段内不切开
- **长句**：一条 ≥ 约 4 秒 → 段内可以中切近

切点从 `0` 起，到 **T** 止。字幕气口只用来在中间落刀，不决定全曲有多长。

### 装段（仍按气口，再按分支收）

H3 单段最长 **15 秒**，最短不要低于 **3 秒**（再短就和邻段合并）。MiniMax 允许 1–4 秒，但 3 秒以下太碎。按硬气口把相邻句子装进一段，装到再加下一句会超过 15 秒就收。

| 分支 | 中间怎么收 |
|---|---|
| MV | 歌词气口。不要切在半句词上。 |
| 讲解 | 讲词意群。同一论点尽量装进一段；论点换了再切。 |
| 脱口秀 | 句界 + 笑点。欢呼、笑声、气口可以单独做反应镜，不要切在半句包袱上。 |

### 对齐到一位小数（给切音频）

气口经常是 11.500、22.066。**不要收成整秒**，只保留一位小数：

1. 切点列表含 `0` 和 **T**。
2. 每个硬气口保留一位小数（22.066 → 22.1）。第一条字幕若不是从 0 起，其起点也是切点（前奏）。
3. 最后一条字幕的结束若 &lt; T，加切点接到 T（尾奏）。
4. 两个切点落到同一 0.1 秒 → 合并，不要空段。
5. 某段 &lt;3 秒 → 并进上一邻段（或下一邻段，看哪边气口更空）。
6. 段与段无重叠、无空洞：下一段起点 = 上一段终点。
7. **所有段时长相加 = T。**

例：T = 89，气口 11.5 / 22.066 / 31.366 / 43.3 / 56.733 / 64.2 / 73.8 / 81.933  
切点：`0 11.5 22.1 31.4 43.3 56.7 64.2 73.8 81.9 89`  
最后 81.9–89 是尾奏。

## 没有 SRT：按秒切

已知全曲 T。从 0 起每段 15 秒，最后一段吃剩余（若余数 &lt;3 则并进倒数第二段）。T 和末段都可以是一位小数。

## 必须输出的时间线字符串

地图确认后、提示词之前，输出一块给 ComfyUI 节点粘贴的字符串，原样、不要改格式：

```
liangmv:v1
0-11.5
11.5-22.1
22.1-31.4
31.4-43.3
43.3-56.7
56.7-64.2
64.2-73.8
73.8-81.9
81.9-89
```

规则：

- 首行固定 `liangmv:v1`
- 之后每行一段 `起点-终点`，最多一位小数，左闭右开意义下连续（本行终点 = 下行起点）
- 第一行起点必须是 `0`
- 最后一行终点 = T
- 每段时长 = 终点 − 起点，范围 3–15

节点只靠这串切音频。提示词仍按段给人看、往节点对话框里填，不塞进这串里。

## 段内镜头

刀数目标不变（画面向约 5 秒一刀，剧情向约 3–4 秒），**气口优先**：

| 句子 | 段内 |
|---|---|
| 短句 | 整句一镜，不切开 |
| 长句 | 可以句内中切近 / 原切近 |
| 硬气口 | 优先落刀 |
| 连句 | 不要当气口硬切 |

提示词 Timeline 用 **本段相对时间**，从 0 到本段时长。相对切点可以带一位小数（句界），最后一镜落到本段时长。
