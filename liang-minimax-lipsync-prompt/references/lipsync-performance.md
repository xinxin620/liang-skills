# 对口型表演

H3 对口型看的是嘴和下颌。唱歌镜要保证这两样在画面里。

## 按分支

**画面向：** 一段里绝大多数镜都是唱歌镜。`Mouth singing`。最多 1 镜可以给手、烟、火、过肩虚实。不要一半演戏。人要在空间里动，不要段段站桩怼脸。

**剧情向：** 大约一半演、一半唱。Timeline 必须逐镜标明。

- **唱歌镜**：嘴可见，下颌贴人声。走路中近或近景。
- **演戏镜**：做事、偷瞄、互动。`Acting, mouth closed, not singing.` 嘴跟表演，不跟人声。

允许唱歌镜有短的前景遮挡、平移露出、虚实层。每次换一种遮挡逻辑。接触点分离（`never fusing`）防融模，不是防遮挡。

## 什么时候可以切走脸

画面向：脸是主信息，但换空间时可以先给中景（人在地点里），再回到嘴。不要「几乎不切走脸」理解成整首大特写。

剧情向：演戏镜可以给对方背影、两人中全、手和本子。唱歌镜不要只给后脑勺或极近只剩一张嘴。

远到看不清下颌的大远，只给 ≤3 秒过渡。

## 身体

站桩张嘴是失败。**慢歌尤其容易写成傻愣着对嘴，禁止。** 运镜 `Locked-off` ≠ 人冻住。机位可以不动，身体仍要有贴场景、贴情绪的简单动作。

每镜写 **一个** 可见的主动作（一句够）。动之前有预备，衣发跟随晚半拍。近景对口型时动作更小，把稳定性让给嘴。

按当下空间和这句词的情绪选，不要当清单每镜都走：

| 词/空间倾向 | 可以写的动作 |
|---|---|
| 路、远、出走 | 慢走一两步，再几乎停 |
| 门、烟、灯、灶 | 停步，看那东西，随词吸气 |
| 月、天空 | 抬头看，再落下 |
| 心伤、回忆 | 低头，肩随气口沉 |
| 风 | 微侧身，衣发晚半拍 |
| 楼梯 | 下一阶，停 |
| 近景对嘴 | 换重心、呼吸、下颌；不要大走位 |

画面向禁止：走过三个房间当推进（换景用硬切）；为了动而甩头、来回踱；把动作写成偷瞄、进教室、擦肩。

剧情向的走、坐、偷瞄仍是戏，唱歌镜同样不能站桩张嘴。

Timeline 禁写全程 `She is still` / 只有 `Mouth singing` 没有身体。写 `slow walk then almost stop`、`looks down`、`weight shifts` 这种能看见的。

| 景别 | 画面向给什么 | 剧情向另给 |
|---|---|---|
| 近景 | 呼吸、眼神、下颌、浅焦 | 写作业、偷看的眼 |
| 中近 | 重心微移、转头、肩 | 迈半步、书抱在胸前 |
| 中全 | 人+光的空间，仍在唱 | 走、进门、他经过 |
| 远 | 3 秒光的地理，尽量少用 | 3 秒地理交代 |

气口写进动作里：`inhales, shoulders drop`。画面向视线看词里的东西（烟、月、火、路）或略偏镜头，不要段段看窗、也不要段段死盯镜头。剧情向偷瞄时视线在他身上。

## 防穿帮

- 手、书、脸、两人：`clearly separated, never fusing`
- 近景一次一件事
- 不要慢动作歌唱
- 不要让模型重唱 / 配音 / 对白覆盖原曲
