# 细节密度：识别锚点与图片正文写到什么颗粒度

`prompt-recipe.md` 管八段式的顺序，本文件管**第 2、3、5 段写多细**：识别锚点、本集状态、
材质与色彩各写几层、每层只答什么问题、可用哪些词。密度是 `craft_default`，
创作者可按平台实测结果加严或放宽。

## 这份文件解决什么

本文件横跨两份产物：《视觉设定.md》的条目锚点，与《图片提示词.md》的正文描述栈。它回答三个问题：

1. 同一个角色，骨架级、标准级、定妆级分别长什么样，什么时候用哪一级；
2. 条目锚点按什么层写、图片正文按什么栈写，两套编号怎么对应、各用在哪份文件；
3. 哪些词能写、哪些词是套话、哪些词只能出现在尾部一句里。

它不改 `AST-04`（条目侧：锚点与状态不混写），也不改 `IMG-02`（正文侧：区分性事实放在泛化质量
语言之前），而是把「可见、可生成、可比较」展开成可执行的层与词。

## 一、三级密度

密度按**每层有几个可比较细节**衡量，不按字数。三级共用同一层序，只增减每层的细节数；
字数带只是成品正文的量纲参考。

| 级别 | 用在哪 | 每层细节 | 中文正文参考长度 | 《视觉设定.md》条目里的写法 |
|---|---|---|---|---|
| 骨架级 | 远景识别、群演、单场次背景人物、快速提案、草图方向 | 0~1 个，只留区分性锚点 | 120~200 字 | 一行锚点，如「窄长脸；黑短卷发；肩背略前倾」 |
| 标准级 | 默认人物/造型/地点/道具条目与板 | 1~2 个 | 250~400 字 | 分号分隔的 3~6 项锚点，每项带可见依据 |
| 定妆级 | 主角定妆、跨集复用、需要跨镜锁脸锁装、要「一眼认出同一个人」 | 3~6 个，逐件到材质与五金 | 450~800 字，多视图可到 900~1200 字 | 锚点分骨相/五官/发型/配饰/服装/体态六行，另配连续性锁 |

判定：**只有下游真的要靠这条参考图认人时才上定妆级**。只要求「像这个角色」用标准级；
要求「后续每一镜都靠它锁脸、锁服装」才上定妆级。定妆级不是默认答案，写满了却不服务识别，
等于给下游增加漂移面，也让锁变得不可读。

细节预算的另一条：**多视图里身份层只写一遍**，再用一致性句（正文 L11）要求其余视图复制；
不要给每个视图各写一遍脸和衣服——重复描述会互相打架，是四视图换脸的主要原因之一。

## 二、《视觉设定.md》条目分层（L1~L7）

本节编号是**条目锚点层**的编号，写给《视觉设定.md》的人物/造型条目；图片正文的层号见第三节，
对应关系见第四节。顺序固定，因为下游提示词照抄时也按这个顺序走。

| 层 | 只回答一个问题 | 写进哪 |
|---|---|---|
| L1 骨相 | 凭什么从轮廓认出这张脸 | Character `识别锚点`（脸型、额头、面中/颧骨、下颌线、下巴、比例） |
| L2 五官 | 眼鼻唇眉各是什么形 | Character `识别锚点`（眼型与眼尾、眼皮、睫毛、瞳色、眼妆、眉形、鼻梁鼻尖、唇形唇色） |
| L3 皮肤 | 表面质感与冷暖 | Character `识别锚点`（冷暖＋深浅＋是否保留纹理；不写「完美肌肤」） |
| L4 发 | 头发怎么长、怎么梳 | 稳定部分（发质、发色、发际）进 Character；梳法、分缝、刘海、长度变化进 Look |
| L5 配饰 | 戴什么、在哪、什么材质 | 不随 Look 变化的进 Character；随造型换的进 Look |
| L6 服装 | 从上到下逐件 | Look `变体锚点`，逐件写版型、领口、袖口、材质、五金、颜色、穿法 |
| L7 体态 | 比例与重心 | Character `识别锚点`（肩背、重心、步态；身高次序写在 `尺度次序`） |

**`reviewed_invariant`**：L4 的「发型长度」既是识别事实又会随造型变。写清哪部分跨造型不变
（发际形状、发质、能否扎起），哪部分属 Look（今天的分缝与长度），否则同一人换个发型就被
判成另一身份。这条约束在图片正文侧同样落在发型层（正文 L6）。

## 三、《图片提示词.md》正文描述栈（L0~L11）

本节编号是**图片提示词正文**的十一层描述栈，写给《图片提示词.md》的可复制正文；
《视觉设定.md》条目请用第二节的 L1~L7。顺序固定：模型对前置内容权重更高，所以
「是什么图、几个人、怎么排」永远在最前，「不许出现什么」永远在最后。

| 层 | 只回答一个问题 | 必须写 | 可省略 | 不要写在这层 |
|---|---|---|---|---|
| L0 用途与版式 | 这是什么图、几个视图、怎么排 | 图种＋视图数量＋左右分区＋画幅 | 视图占比（骨架级可省） | 剧情、情绪表演 |
| L1 风格与渲染通道 | 走哪条渲染管线 | 3D半写实／写实摄影／2D；PBR、SSS、布料与发丝处理 | 渲染词（2D 平涂时删） | 平台参数、权重语法 |
| L2 构图几何 | 每块画面装什么 | 画幅比例、左区内容与占比、右区视图顺序、视平线、裁切红线 | 具体百分比 | 角色外观 |
| L3 身份骨相 | 凭什么认出这张脸 | 脸型→额头→面中/颧骨→下颌线→下巴→整体比例 | 次要骨相 | 妆、发、衣 |
| L4 五官 | 眼鼻唇眉各自什么样 | 眼型与眼尾、双眼皮、睫毛、瞳色与通透度、眼妆晕染；鼻梁鼻尖；唇形唇色闭合；眉形浓淡 | 单项可省，但眼与唇至少各一句 | 情绪表演、剧情 |
| L5 皮肤与妆面 | 表面是什么质感 | 肤色（冷暖＋深浅）、质地、腮红/修容位置 | 妆面（素颜角色可省） | 塑料感、真人骨相等禁止项（放 L11） |
| L6 发型 | 头发怎么长、怎么梳 | 发色、颅顶、分缝、刘海、鬓角碎发、发量、长度、发尾、光泽、发丝可辨度 | 局部发饰（属 L7） | 帽子（属 L7） |
| L7 配饰 | 戴什么、在哪、什么材质 | 位置＋材质＋尺度＋与服装的关系 | 无配饰时写「不佩戴任何配饰」 | 手持剧情道具 |
| L8 服装 | 从上到下穿了什么 | 逐件：内搭→外搭→下装→袜→鞋；每件写版型、领口、袖口、材质纹理、五金、颜色、穿法 | 次要配饰 | 尺度与体态（属 L9） |
| L9 体态与手部 | 身体比例与姿态 | 身高比例、肩宽腰窄、腿长、站姿、手指、脚与鞋底是否完整 | 体态（远景板可省） | 表演动作、剧情走位 |
| L10 光与背景 | 在哪拍、怎么打光 | 主光方向、辅光、轮廓光、背景色与渐变、地面衔接 | 环境光（外景板换成天光） | 气氛形容词 |
| L11 一致性与排除 | 什么绝对不能变、不能出现 | 同一人物＋逐项不得漂移清单；按失败模式分组的禁止项（见第七节） | — | 新的外观要求 |

L8 是密度最容易塌的一层。写法：**一件一句，句内按「版型—结构—材质—五金—颜色」排**，例如
「外搭浅奶油黄短款针织背心，版型合身，前襟小纽扣，针织纹理清晰，露出少量腰腹」。
不要写「时尚甜美上衣」——那是标签，不是可复现的结构。

L11 的一致性句建议三段式：①「四个视图属于同一人物」；②逐项点名不得变化的类别（五官、发型、
妆容、服饰、配饰、身材比例）；③「不得换脸或改变设计」。第②段要照抄本项目实际会漂移的类别，
不要每次照搬同一串。

## 四、两套分层的对应关系

同一组画面事实在两份文件里各有一套编号：**条目层号 + 2 = 正文层号**（L1↔L3 起，至 L7↔L9）。

| 《视觉设定.md》条目层 | 《图片提示词.md》正文层 | 同一组事实 |
|---|---|---|
| L1 骨相 | L3 身份骨相 | 脸型、额头、面中/颧骨、下颌线、下巴、整体比例 |
| L2 五官 | L4 五官 | 眼型与眼尾、眼皮、睫毛、瞳色、眼妆、眉形、鼻、唇 |
| L3 皮肤 | L5 皮肤与妆面 | 肤色冷暖深浅、质地、妆面位置 |
| L4 发 | L6 发型 | 发色、发际/颅顶、分缝、刘海、长度（`reviewed_invariant` 见第二节） |
| L5 配饰 | L7 配饰 | 位置、材质、尺度、与服装的关系 |
| L6 服装 | L8 服装 | 逐件版型、领口袖口、材质纹理、五金、颜色、穿法 |
| L7 体态 | L9 体态与手部 | 肩背、重心、比例、站姿、手部与鞋底完整性 |

正文独有、条目侧没有对应编号的层：

| 正文层 | 条目侧落在哪 |
|---|---|
| L0 用途与版式／L1 风格与渲染通道／L2 构图几何 | 只存在于图片正文；条目不复刻版式指令与渲染管线 |
| L10 光与背景 | 光作为词表维度写进条目（第五节），地点条目另有「光与天气」层（第八节） |
| L11 一致性与排除 | 一致性由《视觉设定.md》的连续性锁承担（见 [连续性锁](continuity-lock.md)）；禁止项属图片正文，不进条目 |

何时用哪套：写《视觉设定.md》条目、核对锚点密度时用 L1~L7；写《图片提示词.md》可复制正文
（含多视图板）时用 L0~L11。**裸写「L4」有歧义**（条目 L4 是发、正文 L4 是五官），跨文档引用
层号时必须写明体系，如「条目 L4」「正文 L6」。改骨相，两套里的 L1 与 L3 要同步改。

一致性靠复述同一词组建立，不靠形容词变化。

项目里所有条目锚点与正文都写这三项，不改成「水灵大眼／琥珀瞳孔／樱桃小嘴」。

## 六、质量词三档

现有规则禁止无验证作用的质量词堆砌，但定妆级提示词确实需要一句渲染校准。按三档处理：

| 档 | 例子 | 处理 |
|---|---|---|
| A 可验证细节 | 漆皮反光／针织罗纹清晰／银链有细扣环／发丝根根可辨 | 鼓励，写在对应层 |
| B 渲染校准句 | 超高清8K细节／电影级角色渲染／PBR 物理渲染／SSS 次表面散射／85mm f/1.8 浅景深 | 受限可用：集中成**尾部一句**，每图最多一次，且必须在 A 档细节之后 |
| C 空泛套话 | 杰作／大师作品／best quality／完美／极致／顶级／无瑕疵／令人惊叹／惊艳 | 不写 |

B 档的用法：

- 只在项目确认走 3D/摄影管线时写；纯 2D 平涂项目写了会与线稿风格打架，删掉；
- 一句写完，集中成尾部一句，不拆成多处，不与 C 档混写；
- 不得用来代替身份与服装层的具体事实（正文 L3~L9，条目 L1~L7）。删掉 B 档句子后，
  正文仍应能认出同一个人，否则是细节不够，不是渲染词不够；
- 相机参数只作「焦段感」提示，不承诺模型精确模拟光学（见
  [生图提示词配方](prompt-recipe.md#光学与表面描述)）。

## 七、禁止项按失败模式分组

禁止项不是越长越好。定妆级样本常见的 30 条清单会稀释正面信息。做法：**先写正面要求，
负面只兜底**；按失败模式分 5 组，每组 2~4 条，只留本项目真出现过的。

| 组 | 典型条目 |
|---|---|
| 身份漂移 | 换脸／换发型／换配色／四视图不一致／多出第二个人物／丢失指定配饰 |
| 解剖错误 | 大头短腿／手指错误／肢体畸形／腿部弯曲／双脚缺失或裁切 |
| 材质错误 | 塑料皮肤／发丝粘连／服装穿模／纽扣错位／金属反光错误／面料廉价 |
| 风格越界 | 2D平面感（写实板）／真人粗犷骨相（3D板）／欧美脸／低模建模 |
| 版式与文字 | 视图重叠／头部或鞋底裁切／文字／水印／品牌Logo／边框／杂乱背景物 |

写作顺序建议：「必须完整展示 X、Y、Z」放在禁止项之前，用正面指令解决裁切，负面只补
「不得裁切」一句。**正面指令负责让模型做对，负面清单负责兜住已知的错**。

## 八、地点、道具、生物的分层

同一套逻辑，换层名，同样先正面后负面、先持久事实后本集状态。下列链条按《图片提示词.md》
正文的展开顺序写；写进《视觉设定.md》条目时只保留持久事实各层，「用途与观察方向」「视图与
背景」「排除」留在正文：

| 类型 | 分层 |
|---|---|
| 地点 | 用途与观察方向 → 空间骨架（内/外、入口、主区、视觉轴）→ 固定锚点两两关系 → 材料与主次色 → 光与天气 → 陈设 state → 空场政策 → 排除 |
| 道具 | 用途与归属 → 轮廓与主要比例 → 尺度参照 → 材料与工艺 → 功能结构（铰链/开口/握持面）→ 当前状态 → 视图与背景 → 文字政策 → 排除 |
| 生物 | 用途 → 形体比例 → 头部与五官形制 → 毛发/鳞羽/斑纹（写分布区与边界）→ 四肢与尾 → 配色 → 静止站姿 → 视图与背景 → 排除 |

道具的密度陷阱是**形容词代替结构**：写「精致古朴的木盒」不如写「掌心大小的浅棕胡桃木扁盒，
盖面铜质搭扣位于前缘正中，接缝可见细木纹」。生物的密度陷阱是**只写质感不写走向**：
「毛发浓密」不如「颈背一列深色鬃毛，斑纹从肩部向腰侧由密转疏」。

## 九、顺序即权重

生图模型对正文前段的服从度通常高于后段（按项目实测记录，不预设固定比例）。因此：

1. 版式与视图几何在前——排错了，后面画得再好也不可用；
2. 身份骨相与五官紧随其后——这是「同一个人」的判据；
3. 发型、配饰、服装按从头到脚的顺序，符合模型对身体的默认扫描顺序；
4. 体态与手部放在服装之后，避免过早的姿势描述干扰服装结构；
5. 光、背景；
6. 一致性句；
7. 渲染校准句（B 档）；
8. 禁止项。

## 十、细节写多了会坏事的三种情况

1. **与身份冲突**：为了「精致」把已接受的方脸、厚重体格写成瓜子脸、九头身。模板默认值
   不得覆盖身份锚点（见 [人物与造型](character-and-look.md#模板槽位不得覆盖身份锚点)）。
2. **与状态冲突**：把临时伤势、雨水、当天妆容写进 Character 持久锚点。
3. **无法生成或无法比较**：写「眼中有星河流转」这类不可执行的比喻，或写下游看不清的
   微观差异（三根睫毛的间距）。锚点必须能被一张参考图证明。

《图片提示词.md》正文侧对应的失败征兆：

- 通篇只有「精致、甜美、高级、氛围感」，删掉后画面不变；
- 服装写成「一套时尚造型」，没有逐件结构与材质；
- 同一层出现四个近义形容词（清纯／纯净／纯洁／清透），实际只表达一件事；
- 多视图里每块画面都重写一遍脸，四张脸互相打架；
- 禁止项比正面描述还长，且大量是「不要模糊、不要畸形」这类通用套话；
- 渲染校准句出现在开头，或同一张图出现三次；
- 细节写满但没人能说出这张图最该被认出的两三个锚点。
