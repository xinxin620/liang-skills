# 高动态模式（武戏 / 打斗 / 高动态三段式）

触发词：**高动态、打斗、武戏、动作戏、近身缠斗、用高动态那套词**。

## 与文戏模式的八处根本差异

| | 文戏模式 | 高动态模式 |
|---|---|---|
| 语言 | 全英文 | **中文写动作 + 英文写镜头指令** |
| 素材引用 | `<Subject 1>` / `<Picture 7>` | `<Subject 1>` / `<Subject 2>`（**标签同上**），描述文字用中文 + "全程锁定" |
| 镜头切分 | `[Shot N]` 独立段，每段自足 | **一条拍链**，用 `the camera cuts to …` 串起 12 拍 |
| 镜头状态 | 可以静止；镜头是旁观者 | **绝不停机**；镜头是在场者，每一击都撞它一下 |
| 段落编号 | S1 / S2 声音锁 | 通常无台词，**不写声音锁** |
| 结尾字段 | `Audio:` + `Forbidden:` + `Mandatory:` | `overall_soundscape:` + `non_diegetic_music:`（H3 官方字段） |
| BGM | **禁止** | **允许且必须有**，在最激烈处一刀切掉 |
| 嘴型纪律 | 独立段，单人镜覆盖 | 无台词时不写；**有台词时照文戏规则补** |

## 结构：三段

```
角色锁定区（Subject 1/2/3）
<第一段：正文，中文动作 + the camera cuts to 英文转场>
overall_soundscape: …
non_diegetic_music: …
```

### 角色锁定区

标签用 `<Subject N>`，与文戏模式**完全一致**；差别只在描述文字用中文。每个 Subject 写齐四件：**面容、服装/道具、身形、以参考图为准 + 全程锁定**。

```
角色锁定区：
<Subject 1>
年轻女子，面容、高髻与金珠发簪、灰蓝米白双层汉服、宽袖、身形以参考图为准，全程锁定。
<Subject 2>
白发老者，面容、长银须、木簪发髻、深灰鹤纹外袍与黑色内袍、粗木杖、身形以参考图为准，全程锁定。
<Subject 3>
场景与站位参考：雨后青石广场，浓雾低垂，暗绿山林背景，冷青灰色调，天光将尽；女子在画面左侧、老者在画面右侧，相隔数步相对而立，全片不换左右、不跨轴线。
```

`<Subject 3>` 是**场景＋站位合一**，末尾的"全片不换左右、不跨轴线"替代了文戏模式的 `Spatial axis` 段。

正文里反复用 **`<Subject 1>` / `<Subject 2>` 点名**，不要图省事写"两人""她和他"——高动态节奏快，用标签点名模型才认得住是谁在做这个动作。

### 状态锚点（续拍的第三种引图方式）

上一镜**还没出片**、手上只有一张构图接近的参考图时，不要硬套成品帧。**用纯文字写一条"当前对局状态参考"当锚点**：

```
<Subject 3>
当前对局状态参考：两人近身相持，绿刃抵老者门面数寸，木杖横在两人之间，林间青雾，冷青色调，绿刃自体强光；女子在画面左侧、老者在画面右侧，全片不换左右、不跨轴线。
```

写齐五件：**双方相对位置 → 武器各自在哪 → 环境与色调 → 屏幕左右 → 轴线声明**。

这是续拍最轻的写法：不需要出片，只要上一镜的动作结果说得清。**但精确度低于成品帧**——成品帧锁住了光线的实际方向与道具的实际摆位，文字只锁住了关系。有条件时优先用成品帧。

编号上，状态锚点占用序列里的下一个号（`<Subject 3>`），**不要跳号**。

## 三段式：12 拍按 3 / 6 / 3 分

| 段 | 拍 | 内容 | 节奏 |
|---|---|---|---|
| **起势** | 1–3 | 凝器亮相 → 定场对峙 → 猛然突进 | 由静到动，一拍加速 |
| **交锋** | 4–9 | 双方交替攻防，**一拍一换手** | 均匀提速，每拍都要有可见后果 |
| **收势** | 10–12 | 全力对冲 → 贴身角力僵持 → 同时卸力分开，定住 | 推到顶再骤然松开 |

**拍数 = 镜头标记的数量**。写完后数一遍 `the camera cuts to` / `the shot transitions to` / `the shot changes to` 出现几次，对不上就合并或拆分——宁可少一拍，不要拍数虚报。

## 单拍公式

```
<camera 标记> <主体> <动作>，<可拍的物质后果>，<镜头反应 / 环境联动>。
```

- **后果必须可见**：青石砸出白印、水膜犁开白线、外袍裂开一道口子、杖身削出白痕、雾气卷出空洞。没有后果的动作等于没发生。
- **镜头当成在场者**：镜头慢半拍被甩开、镜头被冲击波带得剧烈晃动、镜头贴地跟随、360 度环绕。这是高动态最核心的特征——**镜头有物理反应**。
- **每一击都要改变环境**：雾被切开、石屑炸开、木屑齐飞、水被犁开。静止的环境会让打斗失去重量。

## 转场词轮换

三个变体轮着用，不要连续两次一样：

`the camera cuts to …` / `the shot transitions to …` / `the shot changes to …`

## 镜头纪律 ⭐（v2 迭代的核心升级）

**武戏的力量感有七成来自镜头，不是来自动作。** 动作写得再狠，镜头一钉死在地上，成片就是"两个人在打，摄像机在旁边看"。

一段完整的镜头纪律声明，写在正文之后、尾字段之前：

```
镜头纪律：全片每一拍都换机位、换高度、换焦段，镜头始终手持或机械臂运动，绝无静止构图、绝无三脚架定机位、绝无推镜过渡，只硬切。
```

三条硬指标：

| 指标 | 要求 |
|---|---|
| **每拍换机位** | 前后两拍不能是同一个机位、同一高度、同一焦段 |
| **镜头始终在动** | 手持或机械臂；不许静止构图，不许三脚架定机位 |
| **只硬切** | 不许推镜**转场**（推镜在成片里会被渲染成缓慢位移） |

**注意措辞**：要禁的是推镜**转场**，不是推镜本身。`急速推近(Crash Zoom In)`、`环绕推近(Orbiting Dolly In)` 是**镜头内运动**，完全合规。写纪律时用"无推镜转场"，别写"无推镜"，否则会把自己的镜头语言一起禁掉。

### 镜头是被撞的物体，不是旁观者

这是把力量感做出来的关键：**每一击都要让镜头挨一下**。

| 事件 | 镜头反应 |
|---|---|
| 剑成形爆发碧光 | 镜头被碧光正面冲击、猛地向后弹退半米、画面剧烈一震 |
| 火星正对镜头炸开 | 镜头被崩得向后一缩、短暂过曝 |
| 杖尾横扫 | 镜头被杖风带得横移 |
| 剑杖正撞 | 镜头跟着后退数步、抖动失焦一拍 |
| 冲击波 | 镜头被冲击波顶得连续逆滑两画、画面剧烈晃动 |

写法上，把镜头当成一个有质量、有惯性的身体：**被顶开、被弹退、被带偏、失焦一拍、过曝一瞬**。不要写"镜头晃动"，要写"被什么、以什么方式、退了多少"。

### 前景遮挡

让衣料、武器、碎屑**扫过镜头前面**，制造"摄像机就在战场里"的临场感：

- 先被她的衣袖扫过画面、再被甩开、只拍到空荡的夜
- 衣袍扫过镜头前景
- 石屑打在镜头前
- 杖尾从镜头正前方扫过
- 镜头贴着湿石地面向后疾退，水膜与碎雾贴着镜头前掠飞

### 结尾也要动

定格不等于停机。**最后一句必须留一点镜头运动**，否则整段的动能会泄光：

```
… 两人重新锁定，镜头仍在缓慢横移，绝不止静，定格。
```

`绝不止静` 四个字可照用。

### 把镜头绑在武器上（视点镜头）

v2 里镜头是"在场者"，v3 又进了一步：**镜头直接绑在武器或身体部位上**，第一人称冲出去。

```
[剑尖视点] <Subject 1> 第一剑直取 <Subject 2> 门面，镜头绑着剑尖向前冲。
```

| 中文 | 括注 |
|---|---|
| 剑尖视点 | (Blade Cam) |
| 贴手视点 | (Hand Cam) |
| 贴脚视点 | (Foot Cam) |

比"低机位跟拍"更狠——观众不再看人挥剑，而是**跟着剑尖撞过去**。用在起势或交锋的第一个突刺上最有效。

### 物件被打飞：甩出去，再甩回来

武器或饰品被打飞时，**让镜头追上它，再甩回人脸**：

```
<Subject 1> 侧翻后跃避开，杖尖擦过她发髻，金珠发簪被打飞、叮的一声弹进雾里，镜头追着飞出的发簪甩过去，再急速甩回她脸上。
```

一甩一去，镜头就有了**人物之外的第二个动作主体**，画面顿时不空。声音跟上去（`叮的一声`），配乐也留一个点。

### 武器接触面：每拍补分离声明

高动态里最容易糊的是**两人武器相抵的那一瞬**。v1 v2 只写了身体分离，v3 把**接触面**也补上了：

```
剑刃与木杖接触面清晰分离、不融合，两人身体各自独立、不共用肢体。
```

凡是杖身贴剑身、剑脊压杖、掌心握柄的拍，都要补一句接触面分离。`不共用肢体` 这个说法比"不融合"更具体，可照用。

### 攻防节奏：一拍内交替，不要一人一串

v1 v2 是"一拍一人"。v3 更紧凑——**一拍之内双方各自出手一次**：

```
第三剑自下而上撩起……老人被带得侧身再退一步，杖尾急点地面稳住。   ← 她攻，他防
→ 双手改握杖中段，杖身陡然定住，肩腰一沉。                      ← 他聚力
→ 大开大合第一记横扫……                                        ← 他攻
→ 仰身让杖，杖风掀翻她的下摆……                                ← 她防
```

**攻—防—聚力—反击**四步走完，观众才看到"交换"，而不是"轮流表演"。这是紧凑段与松散段的分水岭。


镜头术语用"中文说清 + 英文括注"的双语写法。**这是 v1 → v2 最显著的格式变化**：中文让用户能读，英文让模型认得出是哪个运镜。

| 中文 | 括注 |
|---|---|
| 急速推近 | (Crash Zoom In) |
| 急速拉远 | (Crash Zoom Out) |
| 手持高频抖动 + 轻微滚转 | (Handheld Shake + Dutch Roll) |
| 超低机位贴地仰拍 | (Ultra Low Angle) |
| 贴地跟拍 | (Low Angle Tracking) |
| 贴剑尖低机位前冲 | (Blade-Level Running Cam) |
| 急速上摇 | (Whip Tilt Up) |
| 急速上摇跟拍 | (Whip Tilt Up Tracking) |
| 甩摇 | (Whip Pan) |
| 绕拍 | (Arc Shot) |
| 环绕推近 | (Orbiting Dolly In) |
| 镜头猛降到贴地 | (Floor Drop) |
| 撞击瞬间镜头被气浪顶开 | (Camera Shoved Back) |
| 机械臂 | (camera on a robotic arm) |

## 常见反馈与药方

用户给的修改意见高度模式化，这张表可以直接对照。**改之前先说出病因，再动手**——用户复核的是判断，不是措辞。

| 用户说 | 病因 | 药方 |
|---|---|---|
| **力量感 / 冲击力不够** | 镜头钉死了。动作够狠但镜头不动，成片就成了旁观 | 上「镜头纪律」三条硬指标 + 让每一击撞一下镜头 + 前景遮挡 |
| **角度比较普通** | 全是平视中景，没有极端角度 | 超低机位贴地仰拍、急速上摇、绕拍、俯冲贴地——每拍换高度 |
| 像慢动作 / 太飘 | 模型把高速动作渲染成漂移 | 明写高速、禁用 slow motion / speed ramp；用"弹射"这类爆发动词 |
| 打斗没有重量 | 每一击缺可见后果 | 每拍补物质后果：白痕、裂纹、火星、雾被切开 |
| 越打越糊在一起 | 双人贴身时模型融合身体 | 反融合写在动作当场 + 随时补距离词 |
| 分不清谁在打谁 | 站位没锁死 | 角色锁定区写死左右，正文里反复点名"她 / 他"而非"两人" |
| 结尾泄气 | 定格时镜头停了 | 结尾留一点镜头运动，`绝不止静` |
| 打得太短 / 太潦草 | 拍数不够或某一拍敷衍 | 回数镜头标记；每拍补足"动作 + 后果 + 镜头反应"三件 |

## 反融合：写在动作当场

关键部位同步出画时，**当场**补一句分离声明，不要只丢进结尾禁令：

- 手握剑柄：`手指与剑柄清晰分离、不融合、不穿插`
- 贴身僵持：`身体各自独立、清晰分离、不融合`
- 双人贴身：`两人相隔七步` 这类距离词随时补，防止越打越糊在一起

## 收尾：无胜负是结构性的

高动态武戏的收尾**不靠谁赢**，靠物理上的力竭与松开：

```
两人同时卸力、向后退开，各自滑出数步，杖尖与剑尖同时插进石缝稳住身形，浓雾从两侧合拢，谁都没有倒下。
→ 双人全景定住，左、右，各自喘息，双方重新锁定，定格。
```

四个动作缺一不可：**同时卸力 → 分开滑出 → 借物稳住 → 雾合拢定住**。

## 尾部两行（H3 官方字段）

```
overall_soundscape: Cold wind moving through the courtyard, a low hum rising as the green blade forms, stone shattering under boots, wood and spirit-blade colliding with a metallic crack, cloth tearing, fog hissing as it is blown apart, both fighters' heavy breathing.
non_diegetic_music: Fast percussive battle score with driving taiko and low strings, intensity climbing through each exchange, one sharp sustained chord at the standoff, cutting off hard on the freeze-frame.
```

- `overall_soundscape`：环境声 **+ 每一次碰撞的具体声音**，写到能听出打斗节奏。
- `non_diegetic_music`：**只写节奏走向，不写旋律**。必须给出"在哪个瞬间切掉"（`cutting off hard on the freeze-frame`），否则配乐会一路拖到片尾。

## 词表

### 后果（每拍至少给一个）

### 环境

雨后青石广场 · 浓雾低垂 · 暗绿山林背景 · 冷青灰色调 · 天光将尽 · 青石上的水膜 · 湿石地面 · 碎雾

### 爆发动词（防"飘"）

弹射而出 · 蹬裂 · 炸裂 · 弹退 · 顶退 · 逆滑 · 急停 · 贴地弹射 · 滑铲 · 拧腰让剑 · 借握力旋身 · 硬接 · 横压 · 反手砸

**不要用**：飘、浮、缓缓、悠悠、轻轻。这些词会直接把高速动作拖成慢动作。

## 已知可改进处

**跨版本共性缺陷（v1 v2 v3 都有）**

1. **缺全局 Forbidden 收尾**。正文写了反融合、不换左右，但**字幕、水印、屏幕文字、磨皮、塑料反光**三版都没人管。末尾务必补一行极简 Forbidden——这是这份模板唯一的硬缺口。
   ```
   Forbidden: no subtitles, no on-screen text, no watermark; no soft dissolves or fades; no left-right swaps, no mirroring; no face or hand fusion; no modern objects; no glossy retouch skin, no plastic sheen; no slow motion, no speed ramp.
   ```
2. **拍数虚报**。v1 标称 12 实际 13–14；v2 标称 12 实际 13；v3 连续拍标称 12 实际 13。**标称拍数必须回数**，否则节奏表是假的。
3. **无胜负的收尾在递减**。v1 有「谁都没有倒下」钉死；v2 只留「重新锁定」；v3 改成「她退而不乱」——**这是有意改的**（本镜是追击段的收束，不是全场终局），但**全场最后一镜必须把无胜负明写回来**。
4. **有台词时**必须回到文戏模式的单人镜覆盖法，高动态不豁免嘴型纪律。

**v3 新增待改**

5. **标注镜头词出现两处可疑**：`追臀用镜(Whip Pan)` 疑为「追簪用镜」的误写——该拍正是追金珠发簪；`急速升镜(Tilt Up)` 与括注「升镜」语义重复。**镜头词要能读通**，错了模型会照着错的理解运镜。
6. **`<Subject 3>` 号被占用后，`<Subject 4>` 是否还有必要**。本镜把状态参考编成了 `<Subject 3>`，正文却写 `<锚点4>`——**编号与标签不一致，同一份里出现两套写法**，必须统一。
7. **一拍内交替攻防时，仍要守住"每拍换机位"**。v3 的连续拍（第二剑第三剑连刺、第一记第二记横扫）容易退化成同机位连拍，写完要逐拍核对高度与焦段。
