# 人物模式（角色设定图 / 定妆照 / 四视图）

触发词：**人物提示词、角色设定、定妆照、四视图、四宫格、角色三视图、人物设定图**。

## 定位：它在整条链的上游

```
人物提示词 → 出人物参考图 → 这张图成为分镜里的 <Subject N> / <Picture N> → 出视频
```

**人物提示词的质量，直接决定分镜能不能锁住脸。** 这里少写一项识别特征，分镜里那句"保持参考图中的五官"就少一个抓手，换个角度就可能换人。

所以写人物提示词时，脑里要想着**分镜的 Subject 声明会逐字抄走这些描述**——写的时候就把它们写成可抄的形式。

## 两种产出，一个角色通常两张都要

| 类型 | 用途 | 出图 | 常见编号 |
|---|---|---|---|
| **定妆照**（第一条） | 锁定脸、妆、气质、光位 | 单张，正面半身 | 分镜里的角色图 |
| **四宫格四视图**（第二条） | 锁定服装、身形、比例、多角度 | 一张 2×2 等分 | 分镜里的全身/服装参考 |

定妆照给**脸**，四视图给**衣服和身形**。只出一张，另一头必崩。

## 定妆照结构（七段，顺序固定）

```
正面半身面部定妆照，东方女性，26岁，冷锐、中式写实，保留皮肤纹理与毛孔，冷白肤质，自然光，不磨皮。
窄长菱脸，颧骨高外扩，太阳穴清晰，下巴窄而尖。深窝单眼皮、眼裂细长、眼尾微垂；平直细长眉；鼻梁高且窄、鼻尖略下垂；唇薄偏窄唇峰清晰、唇色冷调薄粉。
冷锐妆：胭脂薄，唇眼一道极细银线，不画唇红。
墨黑长发盘成低髻，发间一支素银细簪。
识别特征：右侧下颌角比左侧更高约1mm；左颧骨上方一处1mm 浅淡斑。
气质冷、锐、不好接近，眼神有压迫感。
冷调侧光 45 度，主光从一侧打来，鼻梁与下颌留清晰阴影，冷硬对比明确，骨相清楚。
正面半身，裁切于胸口以上，面部朝镜头，下颌微抬，目光直视镜头。上身笔直，双手不入画。
浅灰白无缝背景，无文字、无装饰。
负面：…
```

七段顺序：**类型风格 → 脸型骨相 → 五官逐项 → 妆 → 发与佩饰 → 识别特征 → 气质 → 光 → 构图 → 背景 → 负面**

五官**必须逐项分行**，按 眼 → 眉 → 鼻 → 唇 走。合在一句写，模型会漏项。

## 四宫格四视图结构（七段）

```
把参考图中的同一个人成像成竖版 3:4 四宫格角色四视图。四格必须是同一个人、同一张脸、同一套衣服、同一光线，禁止格间换脸。
竖版 3:4，四宫格等分，细线分格，浅灰白无缝底，无场景、无文字、无装饰边框。
写实摄影，保留皮肤纹理与毛孔，不磨皮，冷白肤质。
人物沿用参考图中：34 岁东方男性，长方脸，额、颧、下颌等宽，下颌角约 102 度，下巴平直；内双窄眼、眼裂长而低、内外眼角水平；平直剑眉；直鼻笔直；唇形清晰、唇色少血；两侧与下颌胡须青重。左侧下颌角一道 1.5cm 浅疤，右眉上方一道竖细直疤。黑长直发高束，素银冠。
服装统一四格：黑色立领长款风衣，立领内侧一线极窄冷青色灯带，肩部哑光硬质护肩片，门襟为暗扣直门襟、盒扣简化；左胸内侧露出半截青白玉数据链；下摆两侧开杈，露出内层石墨灰高领针织；直筒战术裤，哑光战术靴；右腕一枚细金窄素环。整体哑光低反光。
左上：全身正面站姿，双手自然垂在身侧，面部覆盖一块中灰色纯色块，覆盖整张脸，保留头部外轮廓，不要裁掉头顶和下巴。
右上：全身背面站姿，头部微侧 15 度，露出后脑、后背的发髻与束起的轮廓。
左下：脸部特写，正面，目平视镜头。
右下：胸以上正面，露出脸和双手，双手自然垂姿，立领灯带与胸袋轮廓清楚。
四格统一侧顶光加冷蓝轮廓光。
负面：换脸、格间不同衣服、裁掉头顶、面部色块漏出到头发或脖子、文字、水印、logo、多手多指、六指、手指畸形
```

第一句是**总纲**，把"同一个人、同一张脸、同一套衣服、同一光线"钉死，并直接点名 `禁止格间换脸`。这一句不能省——四宫格最常见的崩法就是四张脸。

**服装要写到内层**：立领内侧的灯带、左胸露出的半截数据链、下摆开杈露出的内层针织。内层不写，模型会自己编，换角度时内外层接不上。

### 左上格蒙脸：这是刻意为之

左上全身正面那格，**面部覆盖一块中灰色纯色块**。这不是漏写，是设计：

- 四视图的作用是**服装与身形**，脸在这里是干扰项
- 不蒙脸，模型会试图在四个格子里各生成一张脸，四张脸必然不一致——负面里那条「换脸」就是这么来的
- 蒙住后，算力集中到**衣服剪影、比例、领口结构**上
- 关键在于 **`保留头部外轮廓，不要裁掉头顶和下巴`**——否则整体比例会失真

负面里必须补一条 **`面部色块漏出到头发或脖子`**，否则那块灰会糊到发际线和脖子上。

## 量化精度：给模型可测量的锚点

这组提示词最显著的特征是**量化到毫米与度数**：

| 项 | 数值 |
|---|---|
| 下颌角 | 约 102 度 |
| 脸部转向 | 头部微侧 15 度 |
| 光位 | 冷调侧光 45 度 |
| 疤 | 左侧下颌角一道 1.5cm 浅疤 |
| 疤 | 右眉上方一道竖细直疤 |
| 不对称 | 右侧下颌角比左侧更高约 1mm |
| 斑 | 左颧骨上方一处 1mm 浅淡斑 |

**"脸型偏方"这种描述，模型各解各的；"下颌角约 102 度"只有一个解。** 凡是能定量的，一律定量。

## 识别特征：跨镜一致性的真正抓手

疤、痣、左右不对称——**这些看似多余的小瑕疵，是跨镜锁定同一张脸的锚点**。

- 1mm 的瘢痕标记，模型会把它当成"这张脸的指纹"
- 换角度、换光位时，有这个标记，模型更容易认出是同一人
- **分镜里的 `<Subject N>` 声明必须把这个特征逐字抄过去**，否则前功尽弃

所以识别特征要写得**位置精确、尺寸具体、成对出现**（左侧一道疤 + 右下颌角不对称 = 两个交叉验证点）。只写一个，换个角度可能就看不见了。

## 与分镜的接口

人物提示词产出的图，直接成为分镜的参考图：

| 分镜里的写法 | 对应哪张人物图 |
|---|---|
| `Preserve the facial features, hairstyle, costume, body proportions…` | 定妆照 + 四视图 |
| `<Picture N>` 角色图 | 定妆照（脸） |
| 服装描述逐字复制 | 四视图的服装段 |

**铁律：人物提示词里写过的每一项——脸型、五官、识别特征、服装的每一层——在分镜的 Subject 声明里都要能对上。** 对不上，等于白锁。

## 负面清单的三条写法

负面清单不是"把能想到的坏词堆上去"，它有三条硬规矩：

**1. 与正文矛盾的字，一个都不能留。**

女版正文写「面部朝镜头」，负面里却有「面朝镜头」——**模型会困惑**。负面词必须是正文从没要求过的东西。

**2. 用词与正文逐字一致。**

正文说「面部色块」，负面就写「面部色块漏出到头发或脖子」；正文说「灰色块」，负面不能写成「固面块」。**同义但不同字，模型关联不上。**

**3. 只写这个角色真实会崩的那些。**

两版负面高度雷同，但重点不同：

| 类型 | 该防什么 |
|---|---|
| 定妆照 | 手入画（托盘、托腮、扶脸、手挡脸）、角度跑偏（侧脸、背对镜头）、皮肤假（皮褶、油光、塑料感、网红脸、滤镜） |
| 四视图 | 格间不一致（换脸、格间不同衣服）、裁切失误（裁掉头顶）、色块溢出、手部畸形（多手多指、六指、手指畸形） |

定妆照**防手防角度**，四视图**防格间不一致防裁切**——因为这才是它们各自最容易崩的地方。

## 已知可改进处

1. **女版定妆照的负面里有「面朝镜头」，与正文「面部朝镜头」直接矛盾。** 疑为「背对镜头」或「偏头」的误写。**负面清单里出现与要求相反的词，模型会困惑**——必须清掉。
2. **男版四视图负面的「固面块」应为「灰色块」**。负面清单的字必须与正文用词**逐字一致**，否则模型关联不上。
3. **男版「立领灯带与胸袋王锋清楚」的「王锋」**疑为「压锋／轮廓」的误写，建议改成「胸袋轮廓清楚」。
4. **女版负面的「整像素」语义不明**，疑为「塑料感／像素感」的误写。
5. **两版的「第一条／第二条」编号在截图里顺序是反的**（男版先二后一，女版先一）。成稿时按**定妆照 = 1、四视图 = 2** 统一，避免引用错乱。
6. **男女两版结构不对齐**：女版缺四视图，男版各段顺序与女版不同。同项目角色应**共用一套模板**，否则批量生产时无法比对、无法复用。
7. **未写"不可磨皮"之外的反 AI 项**。建议补：无塑料反光、无过度锐化、无高饱和。
